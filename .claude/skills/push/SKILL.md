# Коммит и пуш

## Текущее состояние

Git status:
!`git status -s`

Git diff (статистика):
!`git diff --stat`

Недавние коммиты:
!`git log --oneline -5`

## Инструкции

Ты коммитишь и пушишь текущие изменения. Это НЕ дневная задача — не трогай TASKS.md.

### 1. Проанализируй изменения

- Прочитай `git diff` (staged + unstaged) чтобы понять что было сделано
- Определи характер изменений: рефакторинг, фикс, новая фича, обновление зависимостей и т.д.

### 2. Обнови `CLAUDE.md` (если нужно)

Прочитай текущий `CLAUDE.md` и добавь информацию ТОЛЬКО если изменения затрагивают:
- Структуру проекта (новые файлы)
- CLI флаги (новые или изменённые)
- Chat-команды (новые или изменённые)
- Ключевые решения (значимые архитектурные изменения)

Если изменения косметические (стилизация, мелкий рефакторинг, обновление зависимостей) — CLAUDE.md обновлять не нужно.

НЕ добавляй то, что уже есть. НЕ удаляй существующую информацию.

### 3. Проверь `.gitignore`

- Посмотри `git status` и `git diff` — есть ли новые файлы/директории, которые НЕ должны попасть в репозиторий (кэши, артефакты сборки, конфиги с секретами, node_modules, временные файлы и т.д.)
- Прочитай `.gitignore` и добавь недостающие паттерны если нужно

### 4. Покажи пользователю что будет закоммичено

Выведи:
- Список файлов для коммита
- Предлагаемое коммит-сообщение
- Дождись подтверждения

### 5. Коммит и пуш

- `git add` нужных файлов (конкретные файлы, не `git add .`)
- `git commit` с описательным коммит-сообщением
- `git push`
